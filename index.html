Abstract

Game UI is usually delivered as baked video and sprite sheets, so every restyle sends work back to the artist and every import is a guess about performance.

SYNAPTICA reframes the HUD marketplace around technical art: assets are shader materials with exposed parameters, layouts carry real engine anchors, and each component publishes its draw calls and memory. The prototypes on this site are working WebGL implementations of those ideas.

Differentiators

The only marketplace that ships

Most UI packs are pretty video files. These are engine assets: built for designers to restyle and for engineers to trust.

Shader-driven, not baked

Rings, reticles and bars are drawn with signed distance fields in the fragment shader. Stroke, fill, glow and dissolve are parameters, so a restyle never means re-exporting a sprite sheet.

_Fill · _Thickness · _GlowIntensity · _Dissolve

Budgeted for 60 fps

Every component lists its draw calls, texture memory and overdraw. Shared atlases and material instances keep a full HUD batched, even on mobile.

Target: full HUD ≤ 8 draw calls · ≤ 2 MB VRAM

Engine-native export

Import a prefab, a UMG widget or a Godot scene with clean hierarchies and named parameters. Motion curves from After Effects arrive as engine curves, not video.

.unitypackage · .uasset · .tscn
